 Load Calibration

 The Load Calibration module allows you to load the
 calibration file (.xml format) generated by other modules and transfer the specific
 calibration data to other modules through subscription.

 Note 
 Now this module can only load the calibration files generated by
 N-point calibration, N-image
 calibration and Mapping Calibration
 modules.

 This topic includes:

- 
 How To Use

- 
 Parameter Configuration

- 
 Module Result

 How To Use

 The Load Calibration module can read and output
 the calibration matrix, rotation center, calibration error and pixel accuracy in
 calibration files by loading the calibration file. This module can also manually
 input the image reference coordinates, photograph reference coordinates,
 demonstration coordinates and other information for its successors to subscribe
 to.

 This module is mainly used for calibration trouble-shooting, and can
 output the loaded calibration matrix to the calculation modules. Generally this
 module is used independently for viewing calibration file data;
 It
 can also be used with N-point Calibration, Translation Calibration, and other calibration modules as the
 predecessors.

 Parameter Configuration

 Align File

 You need to set the Set Calibration
 File Path, Refresh
 Signal, and Save Calib
 Data.

 Set Calibration File Path

 Click [img:GUID-A67293D7-03B2-4F66-80BE-40ADC56B8280-high.png] to select
 the calibration file to be loaded.

 Note 
 Only files in .xml format are supported.

 Refresh Signal

 Enter or subscribe to data as a signal of whether to
 refresh the calibration file.
 
- 
 When the parameter is set to 0 or null,
 the selected calibration file is loaded only during
 the first run of the module and is not updated
 thereafter.

- 
 When the parameters are not 0 or null,
 the selected calibration file is reloaded each time
 the module runs. Ensure that the calibration file to
 be read is up to date.

 Save Calib Data

 When enabled, you can save the calibration file
 data to the solution. Even if the solution does not load the
 calibration file, the module can work properly.

 Image Reference Coordinate

 Set the origin and angle of the image reference coordinate
 system through parameter X, Y, and R
 for the successors to subscribe to. You can enter the values or
 subscribe to the predecessor.

 Photograph Reference Coordinate

 Set the origin and angle of the photograph reference
 coordinate system through parameter X,
 Y, and R for the successors to subscribe to. You can enter the
 values or subscribe to the predecessor.

 Demonstration Coordinate

 Set the origin and angle of the demonstration coordinate
 system through parameter X, Y, and R
 for the successors to subscribe to. You can enter the values or
 subscribe to the predecessor.

 Module Result

 Module Result of Load
 Calibration is as follows:

 Time (ms)

 Float. The module running time.

 Angular rotation consistency

 Int. The rotation angle consistency between the image point of
 the rotation axis and the physical point of the rotation center.

 Left and Right-Handed Coordinates Consistency

 Int. 1 indicates the motion mechanism uses a right-handed
 coordinate system whereas -1 indicates the motion mechanism uses a
 left-handed coordinate system.

 Rotation Center Image Coordinate

 Rotation Center Image Coordinate Point

 Rotate Center Image Coordinate X

 Float. The X coordinate of rotation
 center in the image coordinate system.

 Rotate Center Image Coordinate Y

 Float. The Y coordinate of rotation
 center in the image coordinate system.

 Rotate Center Image Coordinate R

 Float. The angle R of rotation center in the
 image coordinate system.

 Rotation Center Physical Coordinate

 Rotation Center Physical Coordinate Point

 Rotation Center Physical Coordinate
 X

 Float. The X coordinate of rotation
 center in the physical coordinate system.

 Rotation Center Physical Coordinate
 Y

 Float. The Y coordinate of rotation
 center in the physical coordinate system.

 Rotation Center Physical Coordinate R

 Float. The angle R of rotation center in the
 physical coordinate system.

 Image Reference Coordinate

 Image Reference Coordinate Point

 Image Reference Coordinate X

 Float. The X coordinate of pixel of
 the feature point when the target is in the
 reference pose.

 Image Reference Coordinate Y

 Float. The Y coordinate of pixel of
 the feature point when the target is in the
 reference pose.

 Image Reference Coordinate R

 Float. The feature edge angle R when the target
 is in the reference pose.

 Photograph Reference Coordinate

 Photograph Reference Coordinate Point

 Photograph Reference Coordinate X

 Float. The X coordinate of the 5th
 point
 during the N-point Calibration
 of the mechanism motion. (when the point numbers
 are 9 or 12.)

 Photograph Reference Coordinate Y

 Float. The Y coordinate of the 5th
 point
 during
 the N-point Calibration of the mechanism motion.
 (when the point numbers are 9 or 12.)

 Photograph Reference Coordinate R

 Float. The angle R of the 5th point
 during
 the N-point Calibration of the mechanism
 motion. (when the point numbers are 9 or 12.)

 Demonstration Coordinate

 Demonstration Coordinate Point

 Demonstration Coordinate X

 Float. The X coordinate of the
 moving mechanism when grasping or fitting the
 target in the reference pose.

 Demonstration Coordinate Y

 Float. The Y coordinate of the
 moving mechanism when grasping or fitting the
 target in the reference pose.

 Demonstration Coordinate R

 Float. The angle R of the moving mechanism when
 grasping or fitting the target.

 Target Photograph Coordinate

 Target Photograph Coordinate Point

 Target Photograph Coordinate X

 Float. The X coordinate of the
 moving machine at the target snapping position
 during the mapping calibration.

 Target Photograph Coordinate Y

 Float. The Y coordinate of the moving
 machine at the target snapping position during the
 mapping calibration.

 Target Photograph Coordinate R

 Float. The angle R of the moving machine at the
 target snapping position during the mapping calibration.

 Object Photograph Coordinate

 Object Photograph Coordinate Point

 Object Photograph Coordinate X

 Float. The X coordinate of the
 motion mechanism at the object snapping position
 during mapping calibration.

 Object Photograph Coordinate Y

 Float. The Y coordinate of the
 motion mechanism at the object snapping position
 during mapping calibration.

 Object Photograph Coordinate R

 Float. The angle R of the motion mechanism at the
 object snapping position during mapping calibration.

 Calibration Matrix

 Float. The transformation relationship between image
 coordinate system and physical coordinate system.

 Module Status

 Int. 0 indicates NG, with the module red; 1 indicates OK, with
 the module green.
