 Scale Transformation

 The Scale Transformation module can convert the
 spacing and width in the image from pixel distance to physical distance in the physical
 coordinate system through the calibration file. 

 Note 
 This module is approximate calculation with a certain degree of errors.
 If you want to obtain a value with accurate calculation, it is recommended to use
 the Calibration Transformation module to convert the feature
 points from the image coordinate system to the physical coordinate system, and then
 calculate the distance with the P2P Measurement module.

 How To Use

 This module should be used with the Image Source module and the Locating modules as the predecessors. The
 Image Source module can provide the images, and locating
 modules can provide the distance between feature points in the image coordinate
 system. Then the Scale Transformation module can convert the
 subscribed pixel distance to physical distance, as shown in the figure below.

 [img:GUID-D818B0BC-14F1-448F-BE04-862800D59DBA-high.png]

 Application Example

 Note 
 In the figure above, the distance between the circle center and the
 edge intersection obtained by the Scale Transformation

 Measurement module on the right.

 Parameter Configuration

 Image Input

 Subscribe to the image by setting the Input Source.

 Scale Transformation

 Subscribe to the distance that is output by the predecessor
 by setting the ImageDist.

 Align File

 You need to set the Load Calibration
 File, Refresh Signal,
 and correction factor.

 Load Calibration File

 Click [img:GUID-A67293D7-03B2-4F66-80BE-40ADC56B8280-high.png] to load the
 calibration file. Calibration files in iwcal, txt, and xml
 formats are supported.

 Refresh Signal

 The parameter is default to 0. Enter or
 subscribe to a parameter value as a refreshing signal. It
 determines whether the Software refreshes the calibration
 file and whether the correction
 factor is valid.

- 
 When the parameter is set to 0 or null,
 the selected calibration file is loaded only during
 the first run of the module and is not updated
 thereafter. And the correction
 factor is invalid.

- 
 When the parameters are not 0 or null,
 the selected calibration file is reloaded each time
 the module runs. Ensure that the calibration file to
 be read is up to date. Now the correction factor is
 valid.

 correction factor

 Enter a correction coefficient to fine-tune the
 subscribed ImageDist
 parameter. It is default to 1 and is often used to correct
 the output physical distance when the calibration data is
 inaccurate. The equation is as follows: the final physical
 distance equals to pixel pitch * single-pixel accuracy *
 correction factor.

 Modify this parameter as required. When you set it to a
 desired value and the Refresh Signal to
 any non-zero value, the output physical distance will be
 corrected.

 Module Result

 Module Result of Scale
 Transformation is as follows:

 Time (ms)

 Float. The module running time.

 Module Status

 Int. 0 indicates NG, with the module red; 1 indicates OK, with
 the module green.

 PixelScale

 Float. The size of per pixel in the physical coordinate
 system.

 PhyDist

 Float. The result obtained by converting the input angle into
 units. 

 PixDist

 Float. The distance of pixels in the physical coordinate
 system.

 TranslateX

 Float. The X-coordinate of the point in the image coordinate
 system mapped from the original point in the world coordinate system
 calculated by calibration matrix.

 TranslateY

 Float. The Y-coordinate of the point in the image coordinate
 system mapped from the original point in the world coordinate system
 calculated by calibration matrix.

 Rotate

 Float. The rotation angle (in radians) of the machine in the
 physical coordinate system relative to the image coordinate system. 
 
- 
 When the rotation angle is positive, the X-axis of
 the physical coordinate system of the mechanism rotates
 counterclockwise by this angle, and its X-axis is consistent
 with the X-axis of the image coordinate system.

- 
 When the rotation angle is negative, the X-axis of
 the physical coordinate system of the mechanism
 rotates
 clockwise by this angle, and its X-axis is
 consistent with the X-axis of the image coordinate system.

 Scale

 Float. The number of pixels per unit length in the image
 coordinate system relative to the world coordinate system.

 Skew

 Float. The difference between the rotation angle of the Y-axis
 and that of the X-axis in the world coordinate system. (Unit: radian)

 Aspect

 Float. The ratio of zoom amount of the Y-axis and that of the
 X-axis in the world coordinate system.
