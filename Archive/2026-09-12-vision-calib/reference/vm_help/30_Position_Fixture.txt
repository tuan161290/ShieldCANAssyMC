 Position Fixture

 Position Fixture module corrects the ROI of the
 subsequent module in real time based on the template matching results. This module is often
 used to correct the motion offset of the target to achieve precise positioning. 

 How It Works

 The algorithm workflow of this module includes the following three main steps:

- 
 Receive target position from Contour Match module. 

- 
 Select a fixture point in the fixture image based on the target
 position. 

 For example, in the left image below, it selects the orange
 point on top of the right pentagram as the fixture point. 

- 
 The module calculates offset and rotation angle relative to the
 fixture point in the image to be corrected. 

- 
 Mark the fixture point in the target image. 

 The fixture point in the unfixed image has the same
 coordinates as the fixture point in the fixture image. 

- 
 Based on the matched target in Contour Match, it selects another point (referred as "unfixtured point") in the
 unfixture image. The position of unfixtured point relative to the
 target is the same with the position of the fixture point relative
 to the target in the fixture image. For example, the black point in
 the right picture below has the same relative position to the
 pentagram as the orange point in the left picture. 

- 
 Based on position of unfixtured point and fixture point
 in the unfixture image, it calculates the pose change of unfixture
 image relative to the fixture image.

 How To Use

 Possible Predecessors/Successor

 In the procedure, possible predecessors of the
 Position Fixture module includes Image Source, Contour Match, and other related modules. Possible successors
 includes Circle Search, Line Search, Caliper, Image Fixture, or other modules. Position Fixture can
 correct ROIs for these successors to acquire a more precise position to
 find targets. 

 Configuration Process

 Position Fixture module configuration
 process is as follows:

- 
 Click Execute to execute the
 flow once to obtain or update the data output by the predecessor
 modules before Position Fixture. 

- 
 Select subscribe input on the Basic
 Parameters. 

- 
 Click Create fixture.

 Cautions

 If the predecessor module is Contour Match, The Position Fixture module
 can automatically subscribes to the scale from them to correct positions of targets
 with different sizes in images with same resolution. 

 Module Result

 The module result of Position Fixture is as
 follows:

 Time (ms)

 Float. The module running time.

 Module Status

 Int. 0 indicates NG, with the module red; 1 indicates OK, with
 the module green.
