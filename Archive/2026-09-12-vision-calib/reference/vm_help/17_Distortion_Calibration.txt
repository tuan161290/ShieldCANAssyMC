 Distortion Calibration

 The Distortion Calibration module is mainly used
 to calibrate a camera using
 images that contain
 a
 checkerboard pattern and generate
 a
 distortion correction file. This module can be applied to positioning and measurement tasks.
 The main distortion sources are radial distortion and perspective distortion during camera
 imaging.

 Note 
 After the correction file is generated by this module, you can use the
 Distortion Correction module to correct the
 images to reduce the deviation caused by distortion. 

 How It Works

 The distortion types that can be processed by this module
 include
 radial distortion, perspective distortion, and radial perspective distortion.

- 
 Radial Distortion: With the distortion center (generally the
 image center) as the central point, the distortion is generated in the
 radial direction. The distortion is generally due to the different
 concentrating
 abilities
 of different areas in
 the
 lens. The farther away from the center, the greater the
 distortion.

 Note 
 The goal of radial distortion correction is to restore the
 distorted line to a straight state.

- 
 Perspective distortion: The distortion that makes objects look
 small in the distance and big on the contrary, which is generally due to a
 certain tilt between the measured object and the camera that leads to the
 angle between the edges of the measured object in the image inconsistent
 with
 reality. The typical case is that the width of the checkerboard is small in
 the distance and big on the contrary. After correction, the size of the
 checkerboard is exactly the same, and the widths of all checkerboard grids
 are
 corrected with the width of the checkerboard near the set correction point
 as the base length.

 Note 
 The goal of perspective distortion correction is to make the
 angle of the measured object in the corrected image consistent
 with
 reality.

- 
 Radial perspective distortion: The image distortion includes both
 radial distortion and perspective distortion.

 Distortion calibration is needed when you want to obtain an undistorted
 image based on the distorted image for successors (such as stitching and measurement
 modules) to process. After the module calculates the correction coefficient, click
 Create Calibration File to save the distortion correction
 coefficient in
 the
 calibration file. 

 Note 
 For the radial perspective distortion, the radial correction
 coefficient and perspective correction coefficient are obtained
 simultaneously.

 Distortion calibration is realized with calibration boards
 such as
 the common
 checkerboard,
 round calibration
 board,
 and
 Hikrobot calibration board.

 Note 

- 
 For details
 on
 calibration
 boards,
 refer
 to the
 How It Works
 section
 of the
 CalibBoard
 Calibration
 topic. 

- 
 Hikrobot calibration board can also be used as an ordinary
 checkerboard calibration board. When
 you use
 the
 Hikrobot calibration
 board
 in the current module, it only needs to search for the
 checkerboard corner points without
 decoding
 to perform calibration.

 How To Use

 The Distortion Calibration module is used with
 Image Source as the predecessor and Distortion Correction as the successor. The
 Image Source module can provide calibration board images with distortion, and the
 calibration file generated by the Distortion Calibration
 module can be subscribed by the Distortion Correction module to correct images with
 the same distortion problems. 

 Module
 Tuning

 When using this module for calibration, you can improve the module
 performance by referring to the methods below.

- 
 Make the calibration board occupy the full field of view to reach
 the best calibration effects.

- 
 When radial distortion is included, set the center of the image
 as CorrectCenterPoint.

- 
 When perspective distortion is included, the image will be
 rotated if the feature points extracted from the image have more rows than
 columns. If the rotation is not desired, ensure that the number of feature
 point rows is fewer than columns before capturing images.

 Parameter Configuration

 This section introduces the configuration of basic parameters and run
 parameters. For the result parameters, see Result Show.

- 
 Basic Parameters:

 Input Source

 Select the calibration board images with distortion
 output by the predecessor.

 Shape

 Set the full screen as ROI or draw rectangular ROI.
 For details, see Draw an ROI.

 Set Calibration File Path

 Update File

 Create Calibration File

 For the three common parameters of calibration
 modules, see N-point Calibration Parameter
 Configuration.

- 
 Run Parameters:

 Correct Center Input

 Select
 a method of entering the correction center point.
 Optional By
 Point or By
 Coordinate.

 Correct Center X/Y

 CorrectCenterPoint

 Set the center point of distortion correction.

 Note 
 When
 you select
 
 radial
 distortion
 in the Distortion Type
 field,
 it
 is recommended to set the center of the
 image as the CorrectCenterPoint
 in
 order to reach the best correction
 effects.

 Distortion Type

 Optional perspective distortion, radial distortion,
 or
 radial perspective distortion.

 Distortion Evaluation

 When enabled, the module starts correcting
 distortions in the input image. All regions of distortion in the
 input image will be straightened as much as possible so as to
 reduce calibration error. Consequently, the module outputs a
 rectified image.

 Post-Correction Points

 When enabled, the specified correction
 point shows a deviation from its initial location in
 the original image. If you want to view the location
 of each correction point and the corresponding error
 coefficient in the calibrated image, enable this
 parameter.

 Error Threshold

 Each correction point comes with an
 evaluation error. If the actual error exceeds the
 configured error threshold, the specific correction
 point will be displayed in red in the calibrated
 image. If the actual error does not exceed the
 configured threshold, the specific correction point
 will be displayed in green in the calibrated image. 

 Note 
 In Result
 Show, you can adjust the font size of
 the error information via the Error Font Size field,
 which aids in clearly displaying multiple pieces
 of error information of correction points.

 Calibration Board Type

 Select
 a checkerboard type according to the actual situation. Optional
 Checkboard Calibration Board, Round Calibration Board, Hikrobot
 I Calibration Board, Hikrobot II Calibration Board, Hikrobot I
 V2 Calibration Board or Hikrobot II V2 Calibration
 Board.

 DOF

 Set the degree of freedom when fitting the homo
 matrix. Optional Scale, Rotation, Aspect
 Ratio, Tilt, Translation, and Transmission
 (perspective transformation), Scale,
 Rotation, Aspect Ratio, Tilt and Translation
 (affine transformation), and Scale,
 Rotation and Translation (similarity
 transformation). The degree of freedom is gradually reduced in
 the three modes above. You are recommended to use the default
 option.

 For example, a square may become a trapezoid in
 perspective transformation, a rectangle in affine
 transformation,
 and a square with different sizes in
 similarity transformation.

 Median Filtering State

 Set whether to perform median filtering before
 extracting corner points. Optional Execution Filtering or No
 Filter. Note that the default value is
 recommended.

 Weighting Function

 Optional Least Squares, Huber, and Tukey. You are
 recommended to use the default value. 

 When selecting Huber or Tukey, you need to configure
 the Weighting Coefficient.

 Weighting Coefficient

 Select the Sigma Clip of the function.
 It is recommended to use the default value.

 Module Result

 Module Result of Distortion
 Calibration is as follows: 

 Time (ms)

 Float. The module running time.

 Module Status

 Int. 0 indicates NG, with the module red; 1 indicates OK, with
 the module green.

 Calibration Error

 Float. The error between the measured value and the ground-true
 value during the calibration. The larger the error, the less accurate it is.
 The allowed error for calibration is from 0.1 to 0.5.

 CalibPointNum

 Int. The number of feature points extracted from the calibration
 board.

 Calibration Point

 CalibPointX

 Float. The X-coordinate of the pixel point at the
 corner of the calibration board.

 CalibPointY

 Float. The Y-coordinate of the pixel point at the
 corner of the calibration board.

 Calibration Point Status

 Float[]. Dependent on the values of Error Threshold and Evaluate
 calibration error. If the actual error of a calibration
 point is greater than the configured error threshold, then the status of
 the calibration point is 0 and the specific correction point in the
 input image is displayed in red; if the actual error of a calibration
 point is less than the configured error threshold, then the status of
 the calibration point is 1 and the specific correction point in the
 input image is displayed in green.

 Evaluation Error

 Float. Represents the overall evaluation error.Note 
 To view this parameter, you need to enable the
 Distortion Evaluation
 feature first.

 Calibration Point Evaluation Error

 Float.
 Represents the evaluation error of the correction point. When the
 parameter is 1, the corresponding correction point is displayed in red;
 when the parameter is 0, the corresponding correction point is displayed
 in green. 

 Note 
 To view this parameter, you need to enable the Distortion Evaluation feature first.

 ROI

 The region of interest used for detection.

 DetectCenterPoint

 DetectCenterX

 Float. The X-coordinate of the center
 point of ROI.

 DetectCenterY

 Float. The Y-coordinate of the center
 point of ROI.

 DetectWidth

 Float. The width of ROI.

 DetectHeight

 Float. The height of ROI.

 DetectAngle

 Float. The rotation angle of the ROI is relative to
 the horizontal direction. A positive angle denotes a clockwise
 rotation, while a negative angle signifies a counterclockwise
 rotation.

 If ROI is in a positive position, the angle is 0
 degree.

 Post-Correction Image

 Post-Correction Image Data

 Image. Represents the output image data obtained
 after the Distortion
 Evaluation feature is enabled.

 Post-Correction Image Width

 Int. Represents the width of the output image
 obtained after the Distortion
 Evaluation feature is enabled.

 Post-Correction Image Height

 Int. Represents the height of the output image
 obtained after the Distortion
 Evaluation feature is enabled.

 Post-Correction Image Pixel Format

 Int. Represents the pixel format of the output
 image obtained after the Distortion
 Evaluation feature is enabled.
