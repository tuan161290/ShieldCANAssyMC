 Calibration Configuration Guide

 The Calibration Configuration Guide tool allows
 you to quickly complete the complex calibration process through step-by-step guide. To open
 the tool window, click Tools in the menu bar and select
 Calibration Configuration Guide. 

 Select the needed Calibration Type and
 click Create to enter the calibration configuration process. 

 Now the three calibration types below are supported.

- 
 
 Static Calibration: Use a stationary camera
 and a
 calibration
 board to determine the transformation relationship between the image coordinate
 system and the physical coordinate system.

- 
 
 Dynamic Calibration: Use the movement of
 feature points to determine the rotation center and the transformation
 relationship between the image coordinate system and the physical coordinate
 system. 

- 
 
 Mapping Calibration: Use feature points to
 determine the transformation relationship between the image coordinate systems
 of two cameras.
