 N-image Calibration

 N-image Calibration has almost the same function
 and purpose as
 the N-point Calibration
 module,
 but
 the main difference between
 them
 lies in the image coordinate system. The N-point Calibration module
 subscribes to the image points output by the predecessor, while the N-image
 Calibration uses
 a
 Hikrobot calibration board to determine the position offset of pixels in
 the image.

 Note 
 The N-image Calibration is more accurate than
 the
 N-point Calibration and it
 needs to be used
 with
 the Hikrobot calibration
 board.

 How It Works

 The Hikrobot calibration board used in this module has labeled the
 coordinate of each corner point in advance, and the image coordinate of the same
 feature point in different images can be obtained by calculating the pixel position
 corresponding to the same labeled coordinate. 

 Then according to the received physical coordinates of the motion
 mechanism, you can get the transformation relationship between the image coordinate
 system and the physical coordinate system of the motion mechanism, which is the
 so-called calibration file.

 Note 

- 
 After obtaining the point information, refer
 to
 the
 How It Works
 section of
 the
 N-point
 calibration
 topic to calculate the transformation
 relationship.

- 
 For more details about Hikrobot calibration boards,
 refer
 to the
 How It
 Works
 section of
 the
 CalibBoard Calibration
 topic.

 How To Use

 When using N-image Calibration, ensure that the
 predecessors include the Image Source module, which is
 necessary to obtain the image of
 the
 Hikrobot calibration board.

 Note 
 At
 least 4 calibration board images need to be imported to the Image
 Source module.

 Parameter Configuration

 This section introduces the configuration of basic parameters and run
 parameters. For the result parameters, see Result Show.

- 
 Basic Parameters:

 Input Source

 Set the image source of the module. In most cases,
 the module directly subscribes to the images output by the
 Image Source module.

 Calibration Points Input

 Optional By
 Point or By
 Coordinate.

 Physical Point

 Physical Coordinate X/Y

 Rotation Angle

 Position and angle information of the coordinate
 points of the motion mechanism. Each image point corresponds to
 a physical point of the motion mechanism.

 Note 
 This parameter and the Physical Coordinate X/Y cannot be used at
 the same time. It is recommended to use the Physical Coordinate X/Y to
 generate the
 rotation
 angle automatically.

 Translation Times

 Sets the number of input points for the
 translation motion, only for translation in the X/Y
 direction. The value is usually set to 9.

 Rotation Times

 Set the number of input points for rotation motion.
 This parameter is required when the rotation axis is not
 co-axial with the image center, and is usually set to 3. Note
 that the rotation is performed at the position of the 5th
 point.

 Phys
 Coord Params

 For details about these parameters, see Physical Coordinate
 Parameters of the N-point calibration.

 Homo Fix

 In the calibration file generated by the module,
 when only translation calibration is performed, the point in the
 top left corner of the checkerboard in the first image is taken
 as the origin of the image coordinate system by default; When
 rotation calibration is also included, the center of rotation is
 taken as the origin of the physical coordinate system by
 default.

 If the mapping relationship does not meet your
 requirements, enable this parameter to define the location of
 the image origin and physical origin.

 Input Mode

 Set the method of obtaining image points
 and physical points. Optional By Point or By
 Coordinate.

 Image Point

 ImagePointX/Y

 Position of image calibration points,
 which are usually subscribed from the
 predecessors.

 Physical Point

 Physical Coordinate X/Y

 Position of the physical coordinate
 origin of the motion mechanism. Each image point
 corresponds to a physical point of the motion
 mechanism.

 Set Calibration File Path

 Update File

 Create Calibration File

 For the three common parameters of calibration
 modules, see N-point Calibration Parameter
 Configuration.

 Clear Image

 Clear cached images that are involved in the
 calibration. The feature is often used for recalibration.

- 
 Run Parameters:

 Camera Movement

 Enable this parameter if the camera has relative
 motion. Otherwise, do not enable the feature because it will
 affect rotation consistency.

 Note 
 This parameter must be set according to the
 actual situation; otherwise, the rotation consistency will
 be
 affected.

 Calibration Board Type

 Optional Hikrobot I Calibration
 Board,
 Hikrobot II Calibration
 Board,
 Hikrobot I V2 Calibration Board or Hikrobot II V2 Calibration
 Board.

 Median Filtering State

 Set whether to perform median filtering before
 extracting corner points. Optional Execution Filtering or No
 Filter. Note that the default value is
 recommended.

 Module Result

 Module Result of N-image
 Calibration is as follows:

 Time (ms)

 Float. The module running time.

 Module Status

 Int. 0 indicates NG, with the module red; 1 indicates OK, with
 the module green.

 CalibStatus

 Float. 0 indicates failed calibration while 1 indicates
 successful calibration.

 Evaluate calibration error status

 Int. 0 indicates the error within the normal range while 1
 indicates an abnormal calibration.

 Rotation Direction

 Int. The rotation direction of the robotic machine. The
 direction of the real 3D physical coordinate system can be adjusted by
 adjusting the rotation angle.

 Quantity of Information

 Int. The number of information collected, stored, and
 transmitted.

 CalibImagePoint

 Image Coordinate X

 Float. The value of pixel X-coordinate of feature
 point during calibration.

 Image Coordinate Y

 Float. The value of pixel Y-coordinate of feature
 point during calibration.

 Pixel Error of Translation Estimation

 Float. The average difference between the measured value and the
 true value during pixel translation. The larger the error, the less accurate
 the measurement result.Note 
 Translating pixels refers to moving pixels in an image
 according to a given offset.

 Max. Error of Translation Pixel

 Float. The maximum difference between the measured value and the
 true value during pixel translation.Note 
 Translating pixels refers to moving pixels in an image
 according to a given offset.

 Corresponding Points of Max. Error of Translation Pixel

 Int. The serial number of the point when there is a maximum
 difference between the measured value and the true value during pixel
 translation.

 Real Error of Translation Estimation

 Float. The difference between the measured value and the true
 value after completing pixel translation.

 Real Max. Error of Translation Pixel

 Float. The maximum difference between the measured value and the
 true value after completing pixel translation.

 Pixel Error of Rotation Estimation

 Float. The average difference between the measured value and the
 true value during pixel rotation. The larger the error, the less accurate
 the measurement result.Note 
 Rotating pixels refers to moving pixels in an image
 according to a given offset.

 Max. Error of Rotation Pixel

 Float. The maximum difference between the measured value and the
 true value during pixel rotation.Note 
 Rotating pixels refers to rotating the pixels in an image
 according to a given offset.

 Corresponding Points of Max. Error of Rotation Pixel

 Float. The serial number of the point where there is the
 greatest difference between the measured value and the true value during
 pixel rotation.

 Real Error of Rotation Estimation

 Float. The average difference between the measured value and the
 true value after rotating the pixels.

 Real Max. Error of Rotation Pixel

 Float. The maximum difference between the measured value and the
 true value after completing pixel rotation.

 Max. Translation Error of the Mechanism: Image Index

 Int. The maximum difference between the measured value and
 the true value during the translation, identifying the location of the
 image with the greatest difference. Note 
 Mechanism translation refers to the movement of a
 robotic arm according to a given offset. 

 Deviation of image movement of mechanism translation and
 mechanism movement

 Float. The difference between the amount of image movement
 and the amount of mechanism movement during the process of mechanism
 translation.

 Dimensional Change of Translation Image of Mechanism

 Float. The scale change of the image during the mechanism
 translation.

 Rotation Variation Among Translation Images of Mechanism

 Float. The rotation change value of the translated image
 during the mechanism translation.

 Max. Translation Error of the Mechanism: Distance Error

 Int. The maximum distance error value between the measured
 value and the true value in the image during institutional
 translation.

 Max. Translation Error of the Mechanism: Image Size
 Changes

 Float. The maximum difference in image scale between
 measured values and true values during the institutional
 translation.

 Max. Translation Error of the Mechanism: Rotation Variation
 Among Images

 Float. The rotational change value of the images with
 a
 maximum difference between the measured value and the
 true value after the mechanism translation.

 Average Error of Mechanism Rotation

 Float. The average error of conversion matrix resulting from
 rotating
 image,
 in millimeters, in machine rotation.

 Note 
 Machine rotation refers to the robotic arm
 rotating
 according to the given delta.

 Max. Error of Mechanism Rotation

 Float. The maximum error of conversion matrix resulting from
 rotating image,
 in
 millimeters, in machine rotation.

 Max. Rotation Error of the Mechanism: Image Index

 Float. The location of the image with the maximum difference
 between the measured value and the true value during the mechanism
 rotation.

 Rotate CenterPoint

 RotateCenterPointX

 Float. The X coordinate of the rotation center
 image calculated by rotating the image.

 RotateCenterPointY

 Float. The Y coordinate of the rotation center
 image calculated by rotating the image.

 X vector

 Mechanism Coordinate System X Direction X

 Float. The X-value of the unit vector on the
 X-axis of the physical coordinate system of the
 institution.

 Mechanism Coordinate System X Direction Y

 Float. The Y-value of the unit vector on the
 X-axis of the physical coordinate system of the
 institution.

 Y vector

 Mechanism Coordinate System Y Direction X

 Float. The X-value of the unit vector on the
 Y-axis of the physical coordinate system of the
 institution.

 Mechanism Coordinate System Y Direction Y

 Float. The Y-value of the unit vector on the
 Y-axis of the physical coordinate system of the
 institution.

 Transfer Ratio Between Y Direction and X Direction

 Float. The proportion of movement in the Y direction to the
 X direction.

 Current Image Num

 Int. The order number of the current image in all images.

 Total Image Count

 Int. The total number of the image.
