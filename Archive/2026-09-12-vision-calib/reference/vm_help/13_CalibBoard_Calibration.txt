 CalibBoard Calibration

 The CalibBoard Calibration module allows you to
 input calibration board images to calculate and output the transformation relationship
 between the image coordinate system and physical coordinate system according to their
 positions. After that, each pixel on the calibration board in the image can be converted to
 the corresponding physical coordinate system.

 CAUTION

 The CalibBoard Calibration module can only be used
 to convert pixels that are in the same plane as the calibration board to the
 correspoonding physical coordinate system. Besides, in order to ensure the
 calibration accuracy, your targets need to be placed on the same plane.

 Figure 1 CalibBoard Calibration Module
 Effects

 How It Works

 Checkerboards
 are divided into the following
 categories:

- 
 Checkerboard calibration board

- 
 Round calibration board

- 
 Hikrobot calibration board (type I and type II)

- 
 Hikrobot calibration board V2 (type I and type II)

 The
 Hikrobot calibration board is based on the checkerboard calibration board and some
 grids are replaced by codes with position information.
 For
 type I,
 one code occupies four grids, and
 for
 type
 II,
 codes are placed in the white grids of the calibration board, as shown in the
 following figure.

 [img:GUID-480C27FC-D711-4E57-B59C-63F14ECDA823-high.png] 
 Figure 2 Calibration Board Type

 Note 
 Hikrobot calibration board can be generated by the Calibration Board Generation tool that
 comes
 with the VM Platform. After obtaining a
 generated calibartion board image, you need to fill in its grids with the color
 that suits your lighting conditions.

 Compared with the other two calibration boards,
 the
 Hikrobot calibration board comes with a physical coordinate system
 and
 supports recording the physical coordinate and
 direction
 of corner
 points
 via
 built-in
 codes on the
 board. When you
 select
 the Hikrobot calibration board, VM Platform will directly
 use its
 own physical coordinate system.

 The
 above four types of calibration boards
 have
 a common image coordinate system, which defines the upper left
 corner of the image
 as
 the
 origin,
 with
 the
 X axis
 extending to the right, and
 the
 Y axis
 extending downwards. However,
 their
 physical coordinate
 systems
 differ.
 The description of these differences is as follows:

- 
 Checkerboard/Round Calibration Board: The coordinate origin is
 the first corner point in the upper left corner, and the coordinate axis is
 parallel to the edge of the checkerboard. 

 Note 
 When the extracted corner point columns are more than the
 rows, the coordinate position and direction will change, and the
 direction with a larger number of feature points is the X-axis, as shown
 in the figure below.

- 
 Hikrobot Calibration Board: As the physical coordinates and
 orientation of corner points are recorded by the code, the default physical
 coordinate system remains the same no matter how the calibration board is
 placed.

 [img:GUID-BBB72C16-574F-434C-9ED0-E1E725FB287D-high.png] 
 Figure 3 Calibration Board Coordinate
 System

 Different types of calibration boards are applicable to different
 scenarios:

- 
 If you only use one camera and pay little attention to the
 origin position of the calibrated physical coordinate system, it is
 recommended to use a checkerboard or circle calibration board.

- 
 If you use multiple cameras and these cameras need to be
 converted to the same physical coordinate
 system,
 the field of view and the checkerboard area of each
 camera
 are
 different, it is recommended to use Hikrobot calibration boards.

 Note 
 When using Hikrobot calibration board, it is necessary to
 interpret the code on the calibration board and ensure in the
 calibration board image the code is large and clear enough (occupies
 about 100 pixels), otherwise the calibration may fail.

 How To Use

 This module is mainly used in measurement and positioning projects.

- 
 Measurement: The calibration results of this module can be used
 to convert specific points in the image to the physical coordinate system,
 and then the measurement is carried out in the physical coordinate
 system.

- 
 Positioning: This module enables the association of multiple
 camera coordinate systems
 and
 can calibrate multiple cameras to the same physical coordinate system.

 Ensure that the predecessors include the Image Source module, which is used to obtain the images of
 calibration boards for calibration.

 Module
 Tuning

 If the calibration fails, refer to the steps below to solve your
 problems.

- 
 Confirm whether the image input from the Image
 Source module is the image of the calibration board.

- 
 Confirm whether you
 have
 selected the correct Calibration
 Board Type, which should be consistent with the type of
 calibration board input from the image source module.

- 
 Check whether other parameters are properly set. For example,
 whether the Dot Type of the round
 calibration board is consistent with the actual image type of the
 calibration board, whether the Dot
 Circularity is set too large, and whether the Edge Threshold is set
 unreasonablly.

 Parameter Configuration

 This section introduces the configuration of basic parameters and run
 parameters. For the result parameters, see Result Show.

- 
 Basic Parameters (Calibration File):

 Set Calibration File Path

 Update File

 Create Calibration File

 For the three common parameters of calibration
 modules, see N-point Calibration Parameter
 Configuration.

- 
 Run Parameters:

 Origin(X)

 Origin(Y)

 The origin of the default physical coordinate system
 can be set for translation in the X/Y direction, in mm. When the
 value is negative, the origin translates in the opposite
 direction of the X/Y axis; When the value is positive, the
 origin is translated in the positive direction of the X/Y
 axis.

 Rotation Angle

 Set the rotation direction and angle of the physical
 coordinate system. When the value of this parameter is negative,
 the coordinate system is rotated counterclockwise;
 when
 the value is positive, the coordinate system is rotated in the
 clockwise direction.

 Coordinate System Mode

 Set the type of physical coordinate system. Optional
 left-handed or right-handed coordinate system, as shown in the
 figure below.

 Note 
 Assuming that the side length of each grid in
 the checkerboard is 1mm in the following figure, the setting
 effect of the above four parameters is as shown in the
 following figure.

 [img:GUID-F4EB1D14-C75B-45FA-82F9-BA3A1DC8E93A-high.png] 
 Figure 4 Parameter Configuration Effects

 Physical Size

 Set the side length of a checkerboard square or the
 center to center distance between adjacent circles in a circle
 grid, in mm.

 Note 
 This parameter must be set according to the
 actual dimensions of the calibration board. Otherwise, the
 resulting pixel to real world mapping obtained during
 calibration will be incorrect.

 Calibration Board Type

 Optional
 Checkboard Calibration Board,
 Round Calibration
 Board,
 Hikrobot I Calibration
 Board,
 Hikrobot II Calibration
 Board,
 Hikrobot I V2 Calibration
 Board or Hikrobot II V2
 Calibration Board. For more
 details, see How It Works.

 For different calibration boards, you need to set
 different parameters.

 When selecting calibration board types other
 than round calibration board

 You need to set the Median Filtering
 State.

 Median Filtering State

 Set whether to perform median filtering before
 extracting corner points. Optional Execution Filtering or No
 Filter. Note that the default value is
 recommended.

 When selecting
 a
 round calibration board

 You need to set the Dot Circularity, Edge Threshold, and
 Dot Type.

 Dot Circularity

 Set the minimum value of
 circularity. If the recognized region is less
 circular than the set value, it is not considered
 a valid circular region.

 Edge Threshold

 Set the effective range of gray
 difference on both sides of the circle edge. When
 the gray difference is not within this range, the
 detected region is not considered a valid circular
 region.

 Dot Type

 Set the type of dots to be
 recognized. Optional Black Dot with
 White Background or White Dot
 with Black Background.

 DOF

 Set the degree of freedom when fitting the homo
 matrix. Optional Scale, Rotation, Aspect
 Ratio, Tilt, Translation, and Transmission
 (perspective transformation), Scale,
 Rotation, Aspect Ratio, Tilt and Translation
 (affine transformation), and Scale,
 Rotation and Translation (similarity
 transformation). The degree of freedom is gradually reduced in
 the three modes above. You are recommended to use the default
 option.

 For example, a square may become a trapezoid in
 perspective transformation, a rectangle in affine
 transformation,
 and a square with different sizes in
 similarity transformation.

 Weighting Function

 Optional Least Squares, Huber, and Tukey. You are
 recommended to use the default value. 

 When selecting Huber or Tukey, you need to configure
 the Weighting Coefficient.

 Weighting Coefficient

 Select the Sigma Clip of the function.
 It is recommended to use the default value.

 Module Result

 Module Result of CalibBoard
 Calibration is as follows:

 Time (ms)

 Float. The module running time.

 Module Status

 Int. 0 indicates NG, with the module red; 1 indicates OK, with
 the module green.

 Calibration Error

 Float. The error between the measured value and the ground-true
 value during the calibration. The larger the error, the less accurate it is.
 The allowed error for calibration is from 0.1 to 0.5.

 Scale

 Float. The number of pixels per unit length in the image
 coordinate system relative to the world coordinate system.

 Calibration Point

 CalibPointX

 Float. The X-coordinate of the pixel point at the
 corner of the calibration board.

 CalibPointY

 Float. The Y-coordinate of the pixel point at the
 corner of the calibration board.

 Calibration Origin

 CalibOriPointX

 Float. The X coordinate of the first corner
 point in the upper left corner of the calibration board.

 CalibOriPointY

 Float. The Y coordinate of the first corner point
 in the upper left corner of the calibration board.

 PosXVector

 CalibOriPointXVecX

 Float. The X value of the X-axis unit vector in
 the physical coordinate system of the calibration board.

 CalibOriPointXVecY

 Float. The Y value of the X-axis unit vector in
 the physical coordinate system of the calibration board.

 PosYVector

 CalibOriPointYVecX

 Float. The X value of the Y-axis unit vector in
 the physical coordinate system of the calibration board.

 CalibOriPointYVecY

 Float. The Y value of the Y-axis unit vector in
 the physical coordinate system of the calibration board.

 ROI

 The region of interest used for detection.

 DetectCenterPoint

 DetectCenterX

 Float. The X-coordinate of the center
 point of ROI.

 DetectCenterY

 Float. The Y-coordinate of the center
 point of ROI.

 DetectWidth

 Float. The width of ROI.

 DetectHeight

 Float. The height of ROI.

 DetectAngle

 Float. The rotation angle of the ROI is relative to
 the horizontal direction. A positive angle denotes a clockwise
 rotation, while a negative angle signifies a counterclockwise
 rotation.

 If ROI is in a positive position, the angle is 0
 degree.

 CalibPointNum

 Int. The number of feature points extracted from the calibration
 board.

 TranslateX

 Float. The X-coordinate of the point in the image coordinate
 system mapped from the original point in the world coordinate system
 calculated by calibration matrix.

 TranslateY

 Float. The Y-coordinate of the point in the image coordinate
 system mapped from the original point in the world coordinate system
 calculated by calibration matrix.

 Rotate

 Float. The rotation angle (in radians) of the machine in the
 physical coordinate system relative to the image coordinate system. 
 
- 
 When the rotation angle is positive, the X-axis of
 the physical coordinate system of the mechanism rotates
 counterclockwise by this angle, and its X-axis is consistent
 with the X-axis of the image coordinate system.

- 
 When the rotation angle is negative, the X-axis of
 the physical coordinate system of the mechanism
 rotates
 clockwise by this angle, and its X-axis is
 consistent with the X-axis of the image coordinate system.

 Skew

 Float. The difference between the rotation angle of the Y-axis
 and that of the X-axis in the world coordinate system. (Unit: radian)

 Aspect

 Float. The ratio of zoom amount of the Y-axis and that of the
 X-axis in the world coordinate system.

 Pixel Accuracy

 Float. The size of per pixel in the physical coordinate
 system
