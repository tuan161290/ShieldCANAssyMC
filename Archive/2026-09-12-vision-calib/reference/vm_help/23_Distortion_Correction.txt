 Distortion Correction

 The Distortion Correction module allows you to
 correct the perspective distortion and lens distortion in the image through the image pixel
 coordinate. The corrected images are more precise. The module is suitable for robotic arm
 application scenarios involving calibration, such as grasping, positioning, and fitting. 

 How It Works

 This module can address the issues of perspective distortion, radial
 distortion, and radial perspective distortion in images, which are mainly
 implemented by loading the calibration file generated by Distortion Calibration.

 How To Use

 Generally, the predecessor module of Distortion
 Correction is Distortion Calibration. The Distortion Calibration module outputs
 a
 calibration file.

 In the following example, the Image Source
 provides the image and adjusts the size attributes. The Distortion
 Calibration module then detects image features from the distorted
 image, calculates the mapping matrix of the corresponding spatial pose in the world
 coordinate system, and generates the calibration file containing image status and
 deviation. With the calibration file, the Distortion
 Correction module corrects the image and outputs it.

Table 2 Run Params

 | 
 
 | 
 Parameters

 | 
 Description

 | 
 Perspective Distortion Correction

 | 
 Perspective distortion exists in images taken with
 wide-angle lenses. The further the target object, the smaller
 the ratio it shows in the image, and the closer the target
 object, the greater the
 ratio
 it shows. 

 The module removes distortion with the calculated
 perspective transformation matrix. This is suitable for
 scenarios where the calibration board tilts and the distortion
 is relatively small.

 | 
 Radical Distortion Correction

 | 
 In images with radical distortion, the distorted
 pixels are centered on the distortion center and deviates along
 the radical direction. 

 In this mode, the operator calculates the radical
 distortion coefficient to remove the radical distortion. This is
 suitable for scenarios where the perspective distortion can be
 retained,
 only the radial distortion is removed.

 | 
 Radical Perspective Distortion Correction

 | 
 In images with radical perspective distortion, the
 distorted pixels are centered on the distortion center and
 deviates along the radical direction. The further the target
 object, the smaller the ratio
 it
 shows in the image, and the closer the target
 object, the greater the ratio
 it
 shows. 

 This mode is suitable for general scenario.

 Module Result

 The module result of Distortion Correction is as
 follows:

 Time (ms)

 Float. The module running time.

 Module Status

 Int. 0 indicates NG, with the module red; 1 indicates OK, with
 the module green.

 Output Image

 Out Image

 Binary. The binary data of the output image.

 Out Image Width

 Int. The width of the output image.

 Out Image Height

 Int. The height of the output image.

 Out Image Pixel Format

 Int. The pixel format of the output image. Eg., 17301501
 indicates Mono8, and 35127316 indicates RGB24.
